ケアマネアセスメントナビ v2（固定版）
========================================

概要
----
ケアマネジャーがアセスメントの聞き取り時に使用する、iPhone・Android・Windows対応のPWAです。
元の「居宅 アセスメントシートR6～」4ページ構成を基準にしています。

v2の主な改善
------------
・大項目ごとにページを切り替える方式に変更（全項目を同一ページに表示しません）
・画面下部に「戻る／次へ」を常時固定
・回答に応じて必要な場合だけ「追加確認」ページを表示
・課題判定は入力画面から分離し、専用ページで「課題あり／課題なし／判断保留」を選択
・自由記述を大幅に減らし、単一選択・複数選択を増加
・本人／家族／CM観察／他職種・書類メモは「＋本人」等を押した時だけ展開
・日付はカレンダー選択式。画面上で西暦＋和暦を併記
・選択内容から記録文を自動形成。記録文は編集可能で、元の選択データは別に保持
・完了確認は大項目単位で表示し、該当項目へ直接戻って修正可能
・PDF／Excel出力、既存4ページ互換レイアウト／新様式に対応

重要なプライバシー仕様
----------------------
・利用者情報、病歴、家族情報、アセスメント内容を外部サーバーへ送信する処理はありません。
・入力データは各端末のIndexedDB内へAES-GCMで暗号化して保存します。
・暗号鍵は6桁PINからPBKDF2で生成します。
・無操作5分で自動ロックします。
・PINを忘れた場合は端末内データを全削除して初期化します。
・バックアップ、クラウド同期、端末間同期はありません。
・ブラウザのサイトデータ削除、端末故障、PIN初期化時は復元できません。
・PDF/Excelとして出力した後のファイルは、端末側で適切に管理してください。

初回配布（HTTPSが必要）
----------------------
PWAとしてiPhone・Android・Windowsへ導入するため、初回だけこのフォルダ一式をHTTPSの静的Webサーバーへ配置します。
GitHub Pagesを利用できます。サーバー側のデータベース、PHP、Node.js等は不要です。

1. v2用に care-assessment-nav-v2 など別のGitHubリポジトリを作成します。
2. このフォルダ内のファイルをリポジトリ直下へアップロードします。
3. Settings → Pages → Deploy from a branch → main / (root) を保存します。
4. 公開URLの index.html を開き、端末別の案内に従ってインストールします。
5. インストール後は主要機能をオフラインで利用できます。

固定版について
--------------
v2は固定版です。同じURL上で自動的に仕様を変更する運用は想定していません。
将来v3を出す場合は別URL・別フォルダで配布してください。

PDF出力
-------
「PDF出力」を押すと印刷用画面を開きます。
iPhone/Android/Windowsの印刷画面で「PDFとして保存」等を選択します。
既存4ページ様式／新様式を選択できます。

Excel出力
---------
外部ライブラリやサーバーを使わず、ブラウザ内で.xlsxを生成します。
「既存4ページ様式」は元Excelの4シート構成・項目体系を基にした互換レイアウトです。
「新様式」には、課題判定・入力内容に加え、作成済みの記録文も出力します。

免責・位置づけ
--------------
本ツールはケアマネジャーのアセスメントの聞き取り・記録・確認漏れ防止を支援するもので、専門職としての判断を代替するものではありません。
